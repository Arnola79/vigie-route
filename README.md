# Vigie Route

Application de conduite : limites de vitesse (TomTom), zones de danger, journal des dépassements, itinéraire plafonné à 110 km/h avec évitement des péages, guidage et carte qui défile.

## Version web (navigateur, iPhone compris)

**https://arnola79.github.io/vigie-route/**

À ouvrir dans Safari ou Chrome, puis « Ajouter à l'écran d'accueil ».
Limites de la version web : le GPS s'arrête si l'écran se verrouille (l'app garde l'écran allumé pendant un trajet), pas de pause de la musique ni de détection d'appel.

## Version Android (APK)

Page **Releases** → « Vigie Route (APK) » → `app-debug.apk`.
L'APK se met à jour tout seul à partir de `index.html` de ce dépôt.
